# Security

If you believe you have found a security issue in any repository owned by this
organization, please report it privately.

1. Preferred: open a private vulnerability report on the affected repository
   (Security tab → "Report a vulnerability").
2. If that option is not available: email **AI@1915south.com** with the
   repository name, a description, and steps to reproduce.

Please do not open a public issue for security reports. We will acknowledge
within five business days.
