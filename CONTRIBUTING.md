# Contributing

The repositories in this organization are private and are worked by 1915 South
staff. External pull requests are not accepted.

For staff: the development process, the proof-of-concept gate, and the rules
behind the pull-request check live in the internal handbook repository
(Crucible). In short:

- Every change reaches a default branch through a pull request.
- Every pull request names a Linear issue; the `crucible / pr-check` workflow
  fails without one.
- Fill in the pull-request template. Its headings are read by tooling; keep
  them as they are.
